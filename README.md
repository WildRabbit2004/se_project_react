# WTWR (What to Wear?)

## About

WTWR is a weather-based clothing recommendation app. It fetches live weather data for your location and suggests clothing items suited to the current conditions, taking the guesswork out of getting dressed.

## Features

- Live weather data pulled from the OpenWeather API
- Clothing recommendations filtered by temperature and conditions
- Weather card that updates based on current weather type and time of day
- Add and preview clothing items through clean, intuitive modals
- Form validation to ensure clothing items are added correctly

## Tech Stack

- **React** — component-based architecture with hooks for state and side effects
- **Vite** — development server and build tool
- **CSS** — organized using BEM methodology with per-component stylesheets
- **OpenWeather API** — provides real-time weather and forecast data
- **JavaScript ES6+** — modern syntax throughout
